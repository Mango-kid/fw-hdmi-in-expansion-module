
# Description
An HDMI input expansion module for the FW laptop. It utalizes the MS213x. As far as I can tell this is the highest preformance HDMI capture chip avalible that can fit in this package and not require serious thermal considerations. 
- USB3.0
- 100ms or better latency at 1080 in MJPEG mode (glass to glass, capture only will be less)
